剑网3 查询

数据源 JX3API。区服/心法支持别名自动匹配（如「乾坤」→乾坤一掷），不填区服时用默认区服。以下指令均可加 [区服] 参数。

物价交易

指令用法
/金价各区服金价行情，图表输出（别名：金币）
/物价 外观名外观黑市成交价走势与明细，图表输出（别名：外观）
/交易行 成品名成品交易行实时报价与材料行情，图表输出（别名：交易行查价、查价）
/成本 成品名制造成本、材料明细与成品价对比，图表输出
/贴吧物价 物品贴吧参考价
/物价 查到非外观物品时会提示并自动改用交易行查价；图表发送失败时自动回退纯文本。

实时事件推送

JX3API 事件通道实时推送：开服 / 新闻 / 版本更新 / 八卦 / 关隘 / 云丛（免费事件）。推送不消耗查询次数，受 QQ 官方主动消息频控约束。

指令用法
/绑定推送本群立即开启事件推送（即时生效，无需重启）；重复发送有友好提示
/取消推送本群立即停止事件推送（即时生效）
/推送状态显示通道连接、区服过滤、目标群、事件类型清单

塔罗牌

牌库：22 张大阿卡纳，牌义定制（含牌序 / 中英文名 / 象征意 / 正逆位牌意）。

指令用法
/塔罗牌单张每日抽牌（带牌面图）
/占卜牌阵抽牌
  • 每日限一次：单张与牌阵分别各锁一次（按「群 + 个人」维度），重复抽取返回当日结果
  • 正逆位各 50%；逆位时牌面图旋转 180° 发送
  • 牌义超长自动分条发送

群记录本

每个群独立的数据本：记事、查询、随机抽取、导出。数据按群隔离，可回复某条消息 + /记 引用原文。

指令用法
/记 [分类] 内容新增记录（别名：记录 / 存 / add）
/智记 内容AI 自动分类后记录（别名：ai记 / 智能记 / 自动记）
/查 分类|关键词 [页]查询记录（别名：查询 / 找 / search）
/抽 [分类]随机抽一条记录（别名：随机 / random）
/分类查看全部分类（别名：目录 / 列表）
/建分类 名称新建分类（别名：建目录）
/删 ID删除记录，限作者或管理员（别名：删除）
/编辑 ID 新内容编辑记录，限作者或管理员（别名：改）
/删分类 名称删除分类（仅管理员）
/预设 add|del|list 名称管理可预设分类（别名：preset）
/导出 [分类] [txt|csv]导出记录文件发到群（别名：导出记录 / export）
/记录帮助插件用法说明（别名：记录说明）

基础功能

  • 兜底提示：未识别的指令会统一提示，不会装死
